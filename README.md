# AMZExpand Landing Page Recreation

A responsive, pixel-perfect recreation of the **AMZExpand Landing Page** built using **HTML5, CSS3, and Vanilla JavaScript** as part of a Front-End Assignment.

The project closely follows the provided Figma design while maintaining clean, semantic HTML, organized CSS, and lightweight JavaScript interactions.

---

## 📌 Project Overview

This project recreates the AMZExpand landing page using the provided starter HTML structure and Figma design.

The implementation focuses on:

- Pixel-perfect UI
- Responsive layouts
- Semantic HTML
- Clean and maintainable CSS
- Lightweight JavaScript interactions
- Cross-device compatibility

---

## 🚀 Features

- Responsive Navigation Bar
- Hero Section with CTA
- Statistics Section
- Feature Cards
- Founder Section
- Testimonials Carousel
- 90-Day Guarantee Section
- FAQ Accordion
- Metrics & Results Section
- Final Call-To-Action
- Responsive Footer

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

No external CSS frameworks or JavaScript libraries were used.
